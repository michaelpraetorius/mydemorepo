# Lichtschalter

Android-App, die das „RECORDING“-Leuchtschild (USB-Controller „HCLEO“) per
Bluetooth ein- und ausschaltet.

Aktueller Stand: **Konzeptphase**. Alles Wichtige steht in
[docs/KONZEPT.md](docs/KONZEPT.md), dort auch die offenen Fragen zum
Bluetooth-Protokoll, die wir vor dem Programmieren klären müssen.
